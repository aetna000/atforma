# 009 — From design conversation to delivery

The user works with AtMem AI Architect as a design partner: clarify an idea, evolve the diagram,
compare options, record decisions, choose a cloud, refine a ROM, and hand off a
versioned specification and infrastructure sketch. Existing discovery stays in place.

## Acceptance

- Cloud run cost and one-off consulting/build effort are separate. Unknowns never become zero.
- ROM uses visible range factors. Detailed charge lines replace coarse lines for their component;
  each needs quantity, units, price, currency, source, date, region and service.
- Missing coverage, stale prices and unresolved questions prevent a claim of a full estimate.
- AWS resource inventory traces every block and wire, distinguishes existing systems,
  and shows implementation gaps rather than silently inventing infrastructure.
- Download one delivery ZIP: editable project, specification, architecture document,
  estimate, decisions, resource schedule, handoff checklist and Terraform sketch.
- All files trace to the same revision and generation time; regenerate after changes.
- Terraform emits native S3 foundations only for explicit AWS S3 blocks. Other services,
  connections and access remain explicit engineering work. The export never runs.
- Undo/redo work for board changes; a new edit clears redo. Start over offers save first,
  clears the entire engagement, and keeps the model connection.
- Existing multi-cloud options, decision revisions, requirements and save/open keep working.

No cloud deployment, credentials collection, live pricing or invented professional-services
rates. Execution and provider-specific production validation remain future work.
