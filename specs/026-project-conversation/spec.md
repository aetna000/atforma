# Project conversation and multimodal consultation

Keep user and architect turns visible and durable per project without a database. Store the transcript in the project file's versioned conversation extension; preserve it through refresh, save, reopen and export/import without changing architecture revisions. Existing projects begin with a welcome message. Save failures must be visible.

Support explicit image/document upload and clipboard image paste, safe formatted answers and clear concrete questions. Original attachments are transient: retain names and types with the conversation and explain that originals need reattaching after reopening. No credential persistence or attachment bytes in project exports. Model context remains bounded independently of the saved transcript.

Compact the shell and reserve canvas space. Keep composer controls below the text field and dialog close controls separate from primary actions. Use architectural action labels (Develop the cloud architecture; Architecting; Model detailed cloud costs).

Limits: project file size remains 2 MB; original images and documents are not archived. Native Gemini CLI vision is explicitly unsupported. Live vision evidence currently covers Codex only; other adapters have contract validation, not live qualification.
