# AtMem AI Architect 0.1.1

First tagged source release, aligned with the refreshed AtMem.ai website and
AtMem 2.3.13, AtFlows 0.1.6 and AtSys 0.3.3. Project files, providers, exports
and the local helper keep their existing behavior and formats.

- The workspace uses the AtMem.ai Architecture Canvas theme from the website's
  shared tokens: self-hosted DM Sans and Manrope fonts (SIL OFL), softer
  floating controls and the AtMem.ai mark with the "AtMem.ai | AI Architect"
  name, page title and favicon.
- The workspace opens in the light theme. A header button switches to dark mode
  and remembers the choice; the diagram canvas follows it. Previously the
  workspace followed the operating system colour scheme.

## Install or update

```sh
git clone https://github.com/aetna000/atmem-ai-architect.git
cd atmem-ai-architect
git checkout v0.1.1
```

Existing checkouts: `git pull` on the default branch, then follow
[INSTALLATION.md](../INSTALLATION.md) to reinstall dependencies and restart.

## Limits

Visual change only. The current scope and unimplemented areas in the README
still apply: AI Architect does not provision cloud resources, and hosted
collaboration and cloud deployment are not available yet.
