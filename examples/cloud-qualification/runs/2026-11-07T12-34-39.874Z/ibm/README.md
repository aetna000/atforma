# IBM Cloud Object Storage storage foundation

Native resources and an SDK adapter for explicit private-object-storage + cloud-storage-principal + storage-object-admin contracts. Object permissions include deletion for this synthetic CRUD scenario. Existing principal permissions and public grants outside this export require review; no default emulator identity is a deployment identity. Azure uses a container-scoped custom data role, GCP a bucket-scoped objectUser grant, IBM a bucket-scoped Writer grant. Existing subscription/project/resource group/COS instance inputs must be reviewed. Provider-managed encryption defaults apply; customer-managed keys and private-network routing are not implemented by this contract. Azure has an authenticated public network endpoint, not a private endpoint.

Emulation exercises object APIs and emitted client functions, not control-plane apply or IAM enforcement. Run terraform init -backend=false, terraform validate, then terraform test in a credential-free directory. Use the standard provider credential chain only for a separately approved account plan. No credentials belong in this export. Generated examples use synthetic placeholders. Production is blocked pending remote state and operational review. Never clear those gates to obtain a pass. SDK adapters accept an explicitly configured authenticated client; install the pinned SDK from requirements.txt in an isolated environment before configuring the authenticated client; SDK dependency installation is operator-owned (Azure azure-storage-blob, GCP google-cloud-storage, IBM S3-compatible boto3/HMAC client).
